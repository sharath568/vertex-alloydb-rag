# On-call

## Rotation

The rotation is one week long and changes every Wednesday at 11:00. Each shift has a primary and a secondary. If the primary doesn't acknowledge a page within 10 minutes, it escalates to the secondary.

## Handover

Write a handover note in the on-call doc that lists open incidents, silenced alerts and anything unusual from the week.
