# Onboarding

## First week

New engineers get access to the staging project on day one and production read-only access after completing the security training. Production write access requires manager approval and two weeks of on-call shadowing.

## Backups

Harbor database backups run every 6 hours and are kept for 14 days. Restores are done by the platform team only; file a ticket in the PLAT queue.
